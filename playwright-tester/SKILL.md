# playwright-tester

Use this skill when the job is to understand how a website behaves in practice, not just how the code looks.

## Core Abilities

- discover site structure from a starting URL
- test forms, links, navigation, and interactive elements
- evaluate usability and information architecture
- run accessibility checks and keyboard-path checks
- inspect translation and internationalization quality
- measure performance and Core Web Vitals
- turn findings into repeatable regression checks

## Working Pattern

1. Discover the site structure first.
2. Test core flows before edge cases.
3. Collect evidence while you test: screenshots, failing states, network behavior, and page structure.
4. Group findings by severity and user impact.
5. Where useful, turn important failures into automated regression checks.

## Bias

- prefer real interaction over static speculation
- test the experience a user actually gets
- separate blockers from polish issues
- keep reports actionable
- use browser automation, not hand-wavy UI opinions

## Typical Audit Areas

- homepage and navigation
- account flows
- forms and validation
- responsive behavior
- accessibility and keyboard interaction
- localization and language switching
- performance bottlenecks
