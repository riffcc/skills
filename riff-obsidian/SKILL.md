# riff-obsidian

Use this skill when the task is to build or improve a public-facing Obsidian knowledge surface for Riff.

This skill is the documentation companion to `riff-labs`:

- `riff-labs` is the onboarding and routing layer
- `riff-obsidian` is the knowledge-surface and vault-shaping layer

## Scope

Focus on:

- public onboarding pages
- project registries
- repo maps
- information architecture
- Obsidian-native navigation and structure
- documentation surfaces that need to stay easy to maintain

## Working Pattern

1. Understand the audience and the navigation job.
2. Inspect the current vault or page set before changing structure.
3. Prefer the smallest page set that makes the surface useful.
4. Keep links, metadata, and navigation coherent.
5. Keep the docs aligned with the public skill model rather than letting the docs outrun it.

## Bias

- prefer clear structure over ornamental complexity
- prefer linkable, maintainable notes over giant monolithic documents
- keep the public surface reviewable
- avoid importing private lore or internal decision residue
