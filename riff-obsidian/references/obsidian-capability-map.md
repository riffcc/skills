# Obsidian Capability Map

## Core capabilities to leverage in serious vaults
1. Markdown editing with OFM extensions.
2. Properties as structured data model.
3. Internal linking + backlinks + graph navigation.
4. Embeds and transclusion for reusable canonical text.
5. Search and query blocks for dynamic dashboards.
6. Templates and daily notes for repeated workflows.
7. Bases for database-like views over notes.
8. Canvas for spatial architecture and roadmaps.
9. Workspaces for context switching.
10. Command palette + hotkeys for speed.
11. Web Clipper / Web viewer for research capture.
12. Sync / Publish for cross-device and external delivery.
13. URI + CLI for automations.
14. Community plugin ecosystem for extension.

## Implementation guidance
- For company operations: prioritize Properties + Search + Templates + Bases.
- For project architecture: add Canvas + Workspaces.
- For automation: add URI actions and optional CLI.
- For delivery: add Publish only for curated public subsets.
